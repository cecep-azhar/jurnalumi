Kebijakan Privasi

Terakhir diperbarui: September 2026

1. Komitmen Privasi Kami (UU PDP No. 27/2022)

JurnalUmi sangat menghargai privasi dan keamanan data keuangan keluarga Anda. Sesuai dengan Undang-Undang Pelindungan Data Pribadi (UU PDP) No. 27 Tahun 2022, kami berkomitmen untuk melindungi, tidak menjual, dan tidak menyalahgunakan data Anda.

2. Data yang Kami Kumpulkan

  • Informasi Akun: Nama, Email, dan kata sandi (dienkripsi).
  • Data Keuangan: Transaksi, dompet, anggaran, dan aset yang Anda masukkan.

3. Penggunaan Data

Data Anda murni digunakan untuk menampilkan dasbor keuangan keluarga Anda. Kami TIDAK membagikan, menjual, atau menganalisis data transaksi Anda untuk pihak ketiga atau pengiklan.

4. Penghapusan Data (Right to Erasure)

Anda memiliki kendali penuh. Kapan pun Anda memutuskan untuk berhenti menggunakan JurnalUmi, Anda dapat menghapus akun beserta SELURUH data transaksi secara permanen melalui menu Pengaturan Akun. Data tidak akan tersisa di server kami.
